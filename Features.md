# ECG Signal Acquisition Features

Electrocardiogram (ECG) signal acquisition is the process of collecting and converting the electrical activity of the heart into a measurable signal for monitoring and diagnosis. It is widely used in biomedical devices, wearable systems, and healthcare monitoring applications.

# 1. Electrode-Based Signal Collection
ECG signals are acquired using electrodes placed on the human body.
Common electrode placements include:
Right Arm (RA)
Left Arm (LA)
Right Leg (RL)
These electrodes detect the electrical impulses generated by the heart.

# 2. Low-Amplitude Signal Detection
ECG signals are very weak and sensitive.
Typical ECG signal amplitude:
0.5mV to 5mV
Therefore, highly sensitive acquisition circuits are required.

# 3. Instrumentation Amplifier
Instrumentation amplifiers are used to amplify weak ECG signals.
Common amplifiers:
AD8232
INA128
Key features:
High Common Mode Rejection Ratio (CMRR)
Low noise
Accurate signal amplification

# 4. Analog Signal Conditioning
Signal conditioning includes:
Amplification
Offset correction
Signal stabilization

Purpose:
To improve signal quality before digital processing.

# 5. Real-Time Monitoring
Supports live ECG waveform display.
Enables continuous patient monitoring and arrhythmia detection.

# 6. Portable and Wearable Support
Modern ECG systems support:
Smart wearable devices
Wireless ECG monitors
IoT healthcare applications
